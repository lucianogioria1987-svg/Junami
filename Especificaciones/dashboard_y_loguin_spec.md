# Especificaciones Módulo Dashboard y Login

1. Limpia el archivo especificaciones/dashboard_y_loguin_spec.md y deja solo las reglas que te proporcioné.
2. Crea el archivo rutas/dashboard_y_loguin.py como un Blueprint real con las funciones login, dashboard y logout.
3. En app.py, elimina definitivamente esas funciones y solo registra el Blueprint dashboard_loguin_bp.
4. Asegúrate de que logout esté en este módulo, ya que es parte del proceso de autenticación, aunque visualmente se use en el Dashboard.
5. Trabaja solo en la rama actual.
